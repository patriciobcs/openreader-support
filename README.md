# OpenReader support

Public bug reports and feature requests for [OpenReader](https://openreader.io),
the local reading and narration app for Apple Silicon Macs running macOS 14 or later.

[Report a problem or request a feature](https://github.com/patriciobcs/openreader-support/issues/new).
Include your app/macOS versions, steps to reproduce, and the result you expected.
Review diagnostic reports before posting: they can include reading excerpts and
playback details. Remove private text, file paths, credentials, and personal information.

For private support, contact contact@openreader.io. Report vulnerabilities
privately to security@openreader.io, rather than posting them in public issues.

This repository contains support information only. The application source is private.
The separate GPL pronunciation helper and its source releases are public at
[openreader-phonemizer-helper](https://github.com/patriciobcs/openreader-phonemizer-helper).
Third-party components keep their respective licenses and notices.
